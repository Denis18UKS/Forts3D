# Changelog

## 0.4.0-beta

- fixed the NeoForge 1.21.1 `ServerPlayer.teleportTo` compilation failure;
- added server-authoritative build costs, build zones and team ownership;
- added per-block structural integrity, artillery damage, repairs and collapse;
- added projectile limits, wind drift, mortar gravity and weapon-specific tuning;
- added functional two-block linked blast doors;
- added research progression, research console, radar and energy shields;
- fixed resource production outside active matches and disconnected structures;
- fixed pause/resume rebuilding starter forts;
- added team scoreboards, friendly-fire handling, starter kits and expanded commands;
- added loot tables, tool tags and automated Java 21 builds.
