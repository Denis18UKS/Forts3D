# Forts 3D — NeoForge 1.21.1

Играбельная расширенная исходная версия переноса ключевого цикла Forts в Minecraft 3D.

## Реализовано
- отдельная вкладка творческого режима **Forts 3D** со всеми предметами мода;
- матчи, красная/синяя команды и наблюдатели;
- металл, энергия, боеприпасы и командные банки;
- реакторы команд, здоровье реакторов и победа при уничтожении;
- несущие конструкции и событийная проверка потерявших связь элементов;
- дерево технологий и расходы на исследования;
- производящие блоки: шахта, аккумулятор, завод боеприпасов;
- оружие с расходом энергии/боеприпасов, перезарядкой и взрывными снарядами;
- строительные блоки, броня, фундамент, двери, силовые кабели;
- радар, щит, мастерская, завод и ремонтная станция;
- серверные настройки и операторские команды;
- админ-планшет с экраном состояния в игровом чате.

## Основные команды
`/forts match create|start|pause|stop`
`/forts join red|blue|spectator`
`/forts status`
`/forts resource <team> <metal|energy|ammo> <amount>`
`/forts tech <team> <technology>`
`/forts config list`
`/forts giveadmin`

## Сборка
Требуется JDK 21. Проект использует NeoForge 21.1.234 и ModDevGradle 2.0.141. Запустите `gradlew build` после добавления стандартного Gradle Wrapper либо импортируйте проект в IntelliJ IDEA как Gradle-проект.

BioTech не изменяется и используется только как архитектурный эталон.
